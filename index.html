Konfigurasi DiperlukanSambungkan ke database Supabase Anda

Aplikasi ini belum tersambung ke database. Ikuti langkah berikut sekali saja:

  1. Buat akun gratis di supabase.com → buat Project baru.
  2. Buka menu SQL Editor di project Anda → jalankan script SQL yang disertakan pada file SETUP-DATABASE.md.
  3. Buka menu Project Settings → API → salin Project URL dan anon public key.
  4. Buka file fleet-maintenance-app.html ini dengan text editor, cari baris berikut di bagian atas kode <script>, lalu ganti dengan nilai Anda:
const SUPABASE_URL = "PASTE_SUPABASE_URL_DISINI"; const SUPABASE_ANON_KEY = "PASTE_SUPABASE_ANON_KEY_DISINI";

Simpan file, lalu buka/refresh ulang halaman ini. Detail lengkap ada di file SETUP-DATABASE.md yang disertakan.

Pengaturan Notifikasi Reminder

Notifikasi Desktop

Munculkan notifikasi di komputer (pojok layar Windows/Mac) begitu ada kendaraan yang masuk waktunya service, meski Anda sedang buka aplikasi/tab lain. Aplikasi harus tetap terbuka (boleh di-minimize) agar bisa mendeteksi.

Template Pesan WA Reminder

Ubah kalimat pengingat yang dikirim lewat tombol WA Reminder. Pakai kode di bawah ini, nanti otomatis diganti sistem sesuai data kendaraan. Khusus untuk pesan yang digabung banyak unit sekaligus (lebih dari 1 kendaraan dari PT yang sama), hanya baris pembuka & penutup yang ikut dipakai — daftar unitnya tetap format baku dari sistem.

Kode yang bisa dipakai: {nama} nama user/driver, {pt} nama PT, {nopol} nomor polisi, {kendaraan} Brand/Model/Type, {tgl_terakhir} & {km_terakhir} service terakhir, {tgl_berikutnya} & {km_berikutnya} estimasi berikutnya. Kode {kendaraan}/{nopol}/{tgl_terakhir}/dst hanya berlaku di pesan 1 unit, pada pesan gabungan baris pembuka cukup pakai {nama} & {pt} saja.
